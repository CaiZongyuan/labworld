# Lab Word 运行工作台交互预览 v1

2026-10-04。用户授权制作预览，尚未接受本版体验，尚未授权正式实现。

## 设计问题

用户能否先了解实验室运行情况，再从待关注设备进入读数、趋势、任务和操作，并确认实际结果？

依据当前 Foundation V1 的对象、观测、命令、任务、来源和历史语义，采用一个完整方案：运行总览、设备目录、空间视图和运行记录；设备详情从侧边展开。沿用真实应用的中性工作台、shadcn Base UI 组件、主题令牌、Lucide 图标和内置资产图片。

仓库 `experience-design.md` 要求方向明确时先制作一个完整方案。本版沿用用户接受的产品建议，没有生成多套互斥布局。

## 运行

在仓库根目录执行：

```bash
pnpm --dir .scratch/lab-operations/v1 install --ignore-workspace --frozen-lockfile
pnpm --dir .scratch/lab-operations/v1 dev
```

打开 <http://127.0.0.1:5196/prototype/lab-operations>。地址使用 `view=overview|devices|space|records` 保留视图。端口 5196 使用严格占用检查；若已有进程，可通过 `pnpm --dir .scratch/lab-operations/v1 exec vite --host 0.0.0.0 --port 5197 --strictPort` 使用另一端口。

## 可以体验

- 扫描设备汇总、关键读数、待关注项和任务进度。
- 按状态、区域、名称或编号筛选设备。
- 查看过期读数的历史缺口、来源、更新时间及任务中断结果。
- 重新启动温度来源；启动中断离心机的新程序，再启动独立的新任务。
- 修改照明电源与目标亮度，观察命令接受与随后实际观测。
- 停止离心任务，经减速后得到取消结果。
- 按记录类别、设备和时间筛选记录，导出当前筛选结果的 CSV。
- 在真实 Three.js 画布中旋转、缩放、点选模型或设备标签。
- 切换深色主题、空实验室，以及加载、断线、身份失效和操作失败场景。

## 模拟范围

这是独立 Vite 应用，不挂载正式路由，不读写真实 API、凭据、数据库或设备。设备、世界订阅、身份恢复、命令结果、历史与实验室设置均由内存场景模拟。刷新重置所有业务状态。操作失败保留原观测；命令接受本身不改变实际状态。程序重新启动保留旧任务结果，只有显式新任务取代当前任务。

趋势使用确定性合成样本展示视觉层级与历史缺口，不能用于科学分析。原始观测 24 小时、已结束记录 30 天是已有产品保留规则，本预览没有实现持久保留。真实对象 TS-03 只有登记身份，没有测量或控制来源。模拟与真实身份独立。

顶端的预览版本、模拟标记、场景选择与重置属于体验工具，位于被评估的产品工作区之外。空间视图使用示意几何，不声称表达真实实验室扫描或设备运动。登记位置不因相机操作变化。
