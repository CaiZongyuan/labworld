产品范围与架构 ​

Lab Word 的产品目标是实验室数字孪生。当前应用提供持久 Lab、独立 Entity、多节点场景、服务器资产库和版本化定义。用户可以编辑布局、登记人工关系，并运行后端照明、温度与离心程序。术语见 CONTEXT。

模型与设备的关系 ​

text
Lab ──登记──> Entity（设备等对象）<──定义── Asset
                 │
                 └──由 Scene Node 呈现 <──外观── Asset Representation

这是当前已建立的 Foundation V1 身份关系：Equipment Model 是三维资产表示，Equipment Instance 是设备类 Entity；Scene Node 的身份与摆放独立于设备身份。同一模型可表示多台设备，同一设备也可有多个节点。登记时固定定义版本及快照；模拟与真实对象保留独立身份，静态对象无需 Binding。

当前呈现层边界 ​

Lab 主入口使用对象目录、多节点场景和 Inspector。摆放、配置与引用可在浏览器和 Agent 之间恢复。指针变换只编辑 Placement。用户显式登记带人工来源的关系。API 拒绝非法空间环。复制创建独立 Entity。新增表示和移除节点保留身份。版本冲突保留草稿，并提供显式恢复。见布局教程。

定义支持、Binding 实现和当前可执行性保持独立。没有观测时显示未知。后端照明区分命令接受与观测。停止后保留最后报告。中断后必须显式启动。布局版本与运行态保持独立。世界订阅提供持久版本、属性更新、有界队列与快照恢复。凭据撤销会结束已有访问。服务就绪与持久能力许可共同决定可操作性。

历史支持设备、类型、时间范围和游标查询。原始观测默认保留 24 小时。已结束命令、任务和事件默认保留 30 天。清理保留身份、配置、最后逐属性观测与在途任务。每个保留属性保持实际时间与新鲜度。删除过期当前任务记录会推进世界版本。历史缺口保持明确。资产库在 /lab/asset 保留单模型预览。Core 管理文件生命周期。Lab 管理稳定引用。

对象生命周期要求 Task 结束、程序停止后才能归档或更换定义。归档保留身份、节点、真实资产引用和保留期内记录。程序或 Task 运行期间可以替换外观。替换更新 Entity 和当前节点，不改变设备行为。显式目录选择记录定义版本。支持运行的模拟定义获得新的当前 Binding。其他选择没有当前 Binding。旧 Run 保留原关联和来源。完整旅程验证组合恢复，并提供独立参考负载命令。

温度传感器在后端以 1Hz 独立采样。每个属性保留值、单位、来源、时间和质量。心跳不刷新旧测量。停止后保留最后值，并在报告期限后过期。过期推进世界版本，布局草稿不受影响。

离心任务由后端推进，关闭浏览器不会结束任务。Command、Run、Task 和结果具有独立可查询身份。任务固定转速、温度和时长。转速与温度达标后才计时，准备和减速不计入任务时长。Stop 经减速后得到 cancelled，正常结束经减速后得到 completed。异常和不确定结果不能变为 completed。后端重启将原 Run 和未结束任务标为 interrupted。用户必须显式启动新 Run。内置转子根据观测 RPM 在客户端旋转，导入 GLB 没有转子映射。

当前实现保持模型原始尺度，并在外部资源依赖、无几何或解码失败时反馈错误、保留前一个可用模型。每个节点独立加载并释放模型资源，选择一个实例不改写其他实例材质；World 快照返回节点及未放置对象引用的资产，模型恢复不依赖目录第一页。

Three.js 相关代码已随 Lab 页面按需加载，并纳入正式包体预算。预览的构建与软件渲染指标不代表目标硬件性能。
