# Catalog miniatures

These PNGs preserve the accepted Foundation v1 catalog artwork from
`preview/lab-foundation-v1` at `10c4c22f875b958c7adc30cf84c7a41d56a4589c`.
They were captured from the `Miniature` element in its asset library with
Chromium at a 1600 x 1000 viewport, with surrounding backgrounds made transparent.
`model.png` uses the same neutral geometry
as `environment.png`, as in the accepted preview. They illustrate reusable
definitions; uploaded GLB bytes are inspected in the real Lab viewport.
