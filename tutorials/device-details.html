从同一对象详情操作设备 ​

目标：从三维空间选择同一个 Entity（对象），区分目标、实际观测、命令和任务结果，并恢复失败的来源重启。

起始状态与源码 ​

先完成空间工作台。使用包含本章实现的当前 checkout。准备一个持久 Lab、两台模拟照明和两台模拟离心机。普通 Member 需要有效会话；Agent 使用相同公开接口，但需要有效 lab:full key。

在仓库根目录运行：

bash
pnpm install --frozen-lockfile
pnpm dev

打开 http://127.0.0.1:5173/lab。登录后先显示三维空间。下面的 Start、Stop 和动作会写入开发数据库。

共享详情提供操作、记录和详情。工作台上下文按部署、身份、Lab 和 Entity 保留目标和尝试。属性判定读取服务器事实，不用心跳推算实际值。设备使用现有生成 SDK，无需新增 API。

在操作页区分目标与实际值 ​

  1. 打开对象目录。

  2. 选择 Light A。

    名称、登记位置、模拟来源和身份类型显示在详情顶部。操作显示关键实际值、单位、质量和时间。尚无报告的属性显示未知 · 无观测。

  3. 选择启动程序。

  4. 等待首条观测。

  5. 将**目标亮度 (%)**设为 23。

  6. 选择设置。

    Command 先显示提交和等待，再显示执行结果。观测亮度只随服务器属性报告变化。accepted 或 succeeded 都不能代替实际观测。

  7. 选择 Light B。

  8. 将目标亮度设为 77。

  9. 返回 Light A。

    A 的目标仍为 23。B 的输入和命令反馈独立。切换对象不会把目标当作测量。请求电源目标保留最后请求，与观测电源分别显示。

目标和操作尝试只保留在当前工作台会话。刷新页面后读取持久实际状态。它们不是后端设备配置。

检查当前值和最后报告值 ​

一个属性只有同时满足以下条件，才显示当前观测：

  • 值符合固定定义的类型。false 和 0 都是有效值；null 和缺失值保持未知。
  • 属性的新鲜度是 current，来源时间已知，质量是 good。
  • 属性属于当前 Binding（运行绑定）和当前正在运行的 Run（程序运行）。

  1. 停止 Light A 的程序。

    已报告的值继续显示为最后报告值。原来源和时间保留。Stop 不等于关闭照明。

  2. 再次启动程序。

    页面显示新的 Run。新 Run 尚未报告的属性继续显示最后值。亮度的新报告不会刷新旧电源属性；心跳也不会刷新它。

  3. 打开详情。

    查看各属性的 Binding、Run、报告序列、来源时间、接收时间、更新时间、有效期、质量和原始新鲜度。当前执行身份与属性原来的身份分别可查。

  4. 打开记录。

    过滤同一 Entity 的既有历史。记录查询不会改变设备状态。保留期和公开查询见运行历史。

恢复来源和不确定命令 ​

  1. 在无在途任务的运行设备上选择重启来源。

  2. 确认重启。

    页面先请求 Stop，成功后才请求 Start。Stop 失败时，不请求 Start。Stop 成功而 Start 失败时，来源保持停止；选择启动程序恢复。新 Run 不续跑旧 Task，也不重放旧动作。

响应丢失时，读取提交结果不确定。保留原参数和原 key，选择重试同一命令。已有 Command 时，选择刷新命令查询原记录。不要用新 key 自动重复动作。旧 Run 的动作不能在新 Run 中重放。

连接中断或服务不可用时，页面保留最后快照并禁用新操作。恢复连接后再确认服务器状态。身份失效或撤销时，重新登录；旧身份的尝试不能用于新身份。

完成并取消离心任务 ​

  1. 选择 Centrifuge A。

  2. 启动程序。

  3. 将目标转速设为 6000 rpm，目标温度设为 22 degC，任务时长设为 6 s。

  4. 选择开始离心。

    后端固定任务参数。准备阶段不计入有效任务时间。达到容差后，后端开始有效计时；任务随后减速。

  5. 等待已完成。

    设备回到 idle。completed 结果仍显示。新 Run 和后续空闲观测不会覆盖结束结果。

  6. 在 Centrifuge B 开始一个 60 s 任务。

  7. 选择停止离心。

  8. 等待减速结束。

    B 的结果变为 cancelled。A 的目标和结果保持独立。停止离心取消 Task；停止程序结束 Run。在途任务期间先取消任务并等待空闲，再停止来源。完整参数范围、后端阶段和中断恢复见离心任务。

验证与下一步 ​

bash
pnpm exec vitest run apps/web/src/lab-device-details.test.tsx apps/web/src/lab-devices.test.tsx apps/web/src/lab-centrifuges.test.tsx

该入口操作真实 Lab Views；MSW 只替代 HTTP。真实 Node/Web 浏览器验收另用隔离服务和持久数据。它检查桌面、已批准窄屏、实际 WebGL 像素、焦点和可点击区域。测试不访问你正在使用的开发数据库。

继续设备趋势，查看同一设备的真实历史读数、缺口与来源。
