- Historical quota, actual 61-second session expiry, engine/M1 persistence and valid-key same-directory signed restart evidence remains reusable while its inputs are unchanged. A new commit ID alone does not invalidate it.
- #49 owns actual Lab/world/Asset/GLB consumers and their unchanged HTTP contracts. Core supplies the seams; Core fixtures do not seed fake Lab routes.
- #50 owns actual Device Program/Task/history/records/trend, SSE lifetime and actual business query-count budgets. The shared engine proof does not impose a new arbitrary 10-statement gate on Core endpoints.
- #51 owns the official full SDK/contracts source switch, client integration and migration removal. Latest explicit scope excludes Electron gates; original M0 records remain unchanged.
- Simplification, independent Standards + Spec review, affected validation and required final-head CI remain integration conditions. Writer receipt or Draft PR existence does not complete #48.
- Rescan evidence bounds per-hash DB callback statements and processing to 100 entries. Total directory discovery still enumerates and sorts all names; no constant latency claim.
- SIGKILL can retain a private signer temporary file in a persistent directory. Fixture cleanup removes only the owned test directory. Existing valid/unknown canonical keys are never automatically replaced; no power-loss durability claim.
