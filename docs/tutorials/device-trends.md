# 在设备详情中查看真实趋势

继续[设备详情](device-details.md)中的同一个 Lab。你需要已登录的 Member 身份和运行中的 Lab Word Server。趋势读取后端保留的属性报告。

## 建立一份温度历史

1. 打开 Lab。
2. 点击**登记对象**。
3. 选择 `sensor@1.0` 和**模拟对象**。
4. 输入 `Trend sensor`，然后登记。
5. 在该对象的**操作**中点击**启动程序**。
6. 等待**当前关键观测有效**。

当前温度来自 World 的逐属性观测。图表查询不会更新这个实际读数。停止来源后，当前值保留为带原时间和来源的最后报告值。

## 查看时间范围与读数

1. 点击**查看趋势**。
2. 在 Inspector 内向下滚动到图表。
3. 选择**1 小时**、**6 小时**或**24 小时**。
4. 查看**查询截至**和**返回 / 原始样本**。
5. 用指针停在一个点上。
6. 用键盘聚焦图表，再按方向键查看读数。
7. 用触屏点击一个点，或读取下面的**趋势读数**表。

横轴使用真实接收时间和 UTC 尺度。每个点保留原值、单位、来源时间、接收时间、来源、Run、Binding 和报告序列。来源时间缺失时显示未知。

后端按时间桶保留首、末、最小和最大真实读数。**简化粒度**是该段的有效秒数。零表示未简化；返回的代表点不是全部原始样本，也不是平均值。纵轴包含返回的真实尖峰。

不同单位各有自己的图表和纵轴。应用不换算单位。空心点与虚线标记质量待确认、较差或来源时间未知的历史。

## 从空间打开最近一分钟

1. 选中这个传感器的场景表示。
2. 点击其读数旁的**最近 1 分钟**。
3. 查看同一 Entity 的**操作**和**1 分钟**范围。

该入口不移动相机，不修改 Placement，也不保存布局草稿。它使用同一个趋势查询和普通设备详情。

离心机的趋势还提供**温度趋势**和**转速趋势**。转速来自实际 `speed` 报告，不使用任务目标值。温度和 RPM 分别查询。

## 识别缺口与恢复

1. 点击**停止程序**。
2. 点击**刷新趋势**。
3. 查看**来源已停止**缺口。
4. 显式启动新程序。
5. 等待新 Run 的观测，再刷新。

新 Run 保留旧报告和原身份。段间不连线、不补零，也不延长过期末端。一个孤立样本仍显示为点。

**正在查询趋势**、**此范围没有样本**、**历史缺口**和**趋势查询失败**有不同含义。展开**数据可用范围**，核对采集、保留与可用起点。

查询失败时，已加载的图表和表格保留原查询截至时间。预算错误提示缩短范围后重试。选择较短范围，再点击**刷新趋势**。空数据不能代替失败结果。

只有当前可见的趋势响应 World 更新，自动查询最多每五秒一次。手动刷新可立即查询。关闭趋势、切换详情标签或隐藏浏览器页面会停止自动刷新。重新显示后读取最新世界对应的历史。

身份失效会停止访问。重新登录后，查询使用新身份的缓存范围。切换 Lab、Entity、属性或时间范围时，旧响应不会进入新结果。

## 使用同一公开查询

Member 与有效 `lab:full` Agent 使用同一生成 SDK。沿用[有界趋势](bounded-trends.md)的凭据和 Entity 身份，运行完整示例。

```bash
node examples/lab/query-trend.mjs
```
