# 查看运行总览并筛选设备

目标：扫描同一 Lab 的设备、任务、关键观测和关注事实，再打开原设备。运行总览与设备目录共用世界订阅和对象详情。

## 起始状态

先完成[设备操作](device-details.md)、[设备趋势](device-trends.md)或[运行记录](lab-records.md)。Lab 中至少登记一台照明设备和一台温度传感器。使用有效 Member 会话。Agent 使用有效的 `lab:full` API key。当前服务使用 Node 24；Linux 与 Windows 不需要 Docker。

在仓库根目录运行 `pnpm install --frozen-lockfile`，再运行 `pnpm dev`。以下查看操作不修改设备、布局或登记位置。设备操作仍会写入持久记录。

源码：[工作台](../../packages/views/src/lab/workbench-context.tsx)、[运行视图](../../packages/views/src/lab/operations-view.tsx)、[汇总与区域](../../packages/views/src/lab/operations-state.ts)、[属性有效性](../../packages/views/src/lab/observation-state.ts)。这些业务规则属于 Lab。Platform Core 继续拥有身份与会话。

## 从汇总打开原设备

1. 打开 `http://127.0.0.1:5173/lab` 并登录。无 `view` 参数时，Lab 先显示“三维空间”。
2. 选择“运行总览”。读取四个汇总：已登记设备、进行中任务、当前有效观测、待关注设备。
3. 选择“已登记设备”。设备目录包含未归档的 instrument、iot、sensor 和 robot Entity。未放置设备也计入。一个 Entity 有多个 Scene Node 时只计一次。
4. 选择设备名称。共用的“对象信息”显示同一 Entity 的实际值、来源、Run、Task 和结果。关闭详情后，焦点返回发起入口。
5. 返回“运行总览”，选择“环境传感器”。列表来自此 Lab 实际登记的传感器。选择 1、6 或 24 小时，读取真实历史样本与缺口。
6. 在“最近活动”选择“打开原对象”。详情显示该记录保存的原结果。新的 Task 或 Run 不替换旧记录的结果。
7. 选择“查看全部运行记录”，按设备、类别和时间继续查询。

总览的最近活动只读取最多 5 项第一页。它不包含原始 Observation，也不代表完整历史。环境趋势复用[设备趋势](device-trends.md)的查询、采样和来源说明。未登记传感器时，页面显示空状态。

## 判断汇总的含义

进行中 Task 的阶段为 pending、preparing、running 或 decelerating。程序 Run 正在运行，不表示它一定有进行中的 Task。

设备所有关键属性都符合固定定义、属于当前 Binding 与正在运行的 Run，并且时间已知、质量 good、新鲜度 current 时，才计入“当前有效观测”。`0` 和 `false` 有效；未知值不补零。更新一个属性或心跳不会刷新另一属性。

“需要关注”合并同一设备已有的中断、失败、不确定结果、过期属性、质量问题和未知来源时间。结果不确定或中断优先；同一优先级按最早相关事实时间排序。正常停止、程序未启动和没有 Binding 分别列出。连接正常不能证明设备正常。本页没有告警确认、通知或工单流程。

## 筛选登记区域并保留空间入口

1. 打开“设备”。在“搜索名称或身份”输入设备名称、完整身份的一部分或已有标签。
2. 选择“运行状态”。汇总按钮也会打开对应集合。
3. 选择“登记区域”，或选择“未登记区域”。区域从人工 `located_in`、`contains` 关系追溯最近的 Location。三维 Placement 不提供区域依据。
4. 选择“仅未放置对象”。设备没有 Scene Node 时仍可查看和操作。
5. 选择“完整对象目录”。三维空间的目录继续提供家具、器皿、位置和模型。
6. 选择“已归档对象”。归档身份和保留期内记录仍可访问。

切换视图保留有效筛选、选中 Entity 和未保存布局草稿。直接访问 `/lab?lab=<lab-uuid>&view=devices&entity=<entity-uuid>` 后刷新，仍打开同一设备。将 Entity 改为不存在的身份，页面显示“找不到此对象”。选择“清除对象链接”后继续查看当前视图。无效 Lab 不会自动替换为另一间实验室。

## 断线后恢复

1. 保持页面打开，在浏览器开发工具中断开网络。
2. 读取“最后同步快照 · 只读”和最后同步时间。已加载内容与输入保留，新写入不可用。最后报告值不表示当前测量。
3. 恢复网络，或选择“重新连接”。工作台刷新世界、可见环境趋势和最近活动。有效筛选与布局草稿保留。
4. 会话失效或撤销时，重新登录。旧身份的订阅与操作尝试不能用于新身份。

趋势或活动查询失败时，保留上次已读取内容并显示查询失败。按相应的刷新或重试按钮恢复。不要用旧曲线、Command accepted 或最后快照证明设备已完成动作。

## 验证

从仓库根目录运行：

```bash
pnpm exec vitest run apps/web/src/lab-operations.test.tsx
pnpm test:e2e tests/e2e/lab-operations.spec.ts
```

Views 检查只用 MSW 替代 HTTP。浏览器检查使用隔离 Node 服务与临时持久目录，不读取已有开发数据。它核对普通 Member、第二个浏览器和 Agent 的同一世界，以及桌面与既有约定窄屏。CI 继续检查原世界、实时消息与包体预算。
