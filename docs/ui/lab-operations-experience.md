# Lab Word 运行工作台体验 v1

状态：用户于 2026-10-04 反馈“我觉得还不错”，认可 v1，并指定 [TanStack Charts](https://tanstack.com/charts/latest/docs/overview) 作为正式 charts。用户随后请求使用 `to-spec` 形成规格。正式实现尚未开始，本记录区分接受的体验和模拟能力。

## 接受的方向

Lab 首屏展示运行总览，以简短汇总、设备表和待关注列表为主。设备详情从侧边展开，工作视图包括运行总览、设备、空间和运行记录。日常旅程从总览发现对象，进入来源、趋势或任务，执行操作，再核对实际结果。

沿用现有 Lab Word 应用壳、shadcn Base UI、主题令牌、Lucide 图标和内置设备图片。总览、详情、设备操作与空间之间保持同一 Entity。数据过期、程序中断、正常停止、未知与尚未接入分别呈现，模拟与真实对象保留独立身份。

用户认可整体方向不等于逐项确认模拟功能。本轮规格将正式范围明确为已有信息底座上的运行呈现、有界趋势与 Lab 级记录查询；Lab 名称编辑、示例资产弹窗及故障注入不成为新增业务合同。

## 真实性

Three.js 画布、相机、模型点选和实际 PNG 资源运行。设备状态、命令、任务、历史、身份与网络场景由独立内存模拟器提供，刷新重置。曲线使用合成样本，未使用 TanStack Charts。预览不访问正式 API、数据库、身份或设备，不验证后端关闭浏览器继续运行与持久保留。

正式实现使用既有真实设备程序与持久记录；图表替换为固定发布的 TanStack Charts。来源/时间/质量与 Run 边界保留，曲线缺口由业务数据明确产生。库的官方 API、版本和限制见 [调查记录](../research/2026-10-04-tanstack-charts-operations-workbench.md)。

## 验证与反馈

v1 的类型检查、构建与 15 项浏览器检查通过。证据包含桌面、320px/390px、浅/深主题、过期来源恢复、命令接受与实际观测、新 Run 保留中断 Task、新任务完成、减速取消、失败不改写观测、记录导出、断线恢复、空/加载/身份状态，以及真实三维像素、运动、取景、点选与无重叠标签。没有页面错误或正式 API 请求。

截图和原始 JSON 在版本的 `evidence/` 目录。软件渲染像素只提供体验证据；它们不证明目标硬件容量、正式业务权限或真实后端行为。

用户同日确认验收入口：“按此验收（推荐）”。主要入口为真实应用浏览器的“总览 → 设备 → 趋势/任务 → 操作结果”；新增趋势和跨设备查询用公开 HTTP 补充缺口、范围、权限与容量合同。复用已有 Lab 测试入口，不测试私有 hooks 或图表内部对象。
