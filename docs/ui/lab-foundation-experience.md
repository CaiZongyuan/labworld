# Digital Twin Foundation — 交互预览 v1

状态：用户于 2026-10-02 接受 v1，反馈“效果很好，你可以去实现了”，授权按该体验正式实现。输入来自[已收敛的 Foundation V1 计划](../plans/Labworld-Digital-Twin-Foundation-V1-plan.md)，沿用[已接受的 Viewer 视觉方向](lab-viewer-experience.md)、[现有应用壳](web-experience.md)和[体验设计流程](../agents/experience-design.md)。本记录描述已接受的隔离预览，正式产品实现与验收另行进行。

## 要回答的问题

用户能否在同一个工作台中，从可复用资产建立独立实验室对象、调整三维摆放、查看登记位置、执行设备任务，并理解命令、观测与任务结果？普通用户和 Agent 是否能以相同方式操作同一个世界？

首版采用一个完整方案：现有全局导航；Lab 内左侧对象目录、中间三维场景、右侧实体详情，场景下方显示事件与任务。布局编辑与运行查看分别有入口；普通拖动与显式登记位置的区别通过属性面板表达。

## 可试用旅程

1. 从资产库选择内置定义或导入 GLB，为新对象命名并加入 Lab。
2. 在编辑布局中拖动、旋转或复制为独立实例，保存后刷新恢复布局与模型资源。
3. 选择两台离心机中的一台，设置转速、温度和时长，观察准备、达标后计时、减速和完成；另一次运行使用 Stop，观察 cancelled 与设备 idle 的区别。
4. 切换照明和亮度；查看传感器连续观测；查看机械臂已声明但未实现的能力。
5. 修改三维坐标后核对登记位置未变；再显式修改登记关系，观察人工来源标记。
6. 移除场景节点后在对象目录中找回身份并放回场景；停止设备程序后归档对象，保留可查记录。
7. 在独立的 Agent 客户端中查询世界、创建照明或发出 Start/Stop，观察同一对象和带操作者来源的事件。

预览工具条位于产品工作区外，提供正常、空场景、加载、连接中断、保存冲突、身份失效、运行端重启和设备异常场景。时间默认加速 30 倍，可切换 1 倍或 120 倍。主题和语言复用现有应用壳；窄屏将场景与详情纵向排列。

## 真实性与限制

三维几何、渲染、相机、点选、指针拖动、模型导入及浏览器存储实际运行。内置模型为本次预览创建的示意几何。

设备程序、网络故障、身份、World API 和 Agent 请求由浏览器内模拟器驱动。保存只写入独立的 `PROTOTYPE-lab-foundation-v1` 浏览器数据库，保留布局与模型资源；真实刷新会重置模拟运行和任务事件。关闭浏览器继续运行、真实多客户端一致性、后端任务持久化与历史清理仍是正式产品合同，预览不声称已经实现。

历史面板的 24 小时/30 天标签表达已确认策略；当前只保留有界事件样本。自定义 GLB 在本版作为静态对象表达，完整压缩解码与任意模型的设备语义映射留待实际加载链路验证。

## 验证与版本留存

19 项浏览器检查已通过，覆盖真实画布像素、设备实例隔离、任务完成/取消、照明、独立位置关系、GLB 导入及真实刷新、指针拖动、保存冲突、Agent 操作、断线/身份恢复、运行中断、节点移除、描述型机器人及中英文/深色/窄屏布局。另有 3 项定向检查通过，覆盖停止程序后归档并可查身份、被引用资产拒绝删除，以及 320px 英文工具栏和注册弹窗的可操作性。两组均未记录页面错误；逐项结果与截图保存在版本的 `evidence/` 目录。

检查使用 Chromium 与 SwiftShader。图像和交互证据用于评估体验，不代表目标硬件的性能结果或真实应用验收。预览独立执行 TypeScript 检查和 Vite 构建；生产包体与后端检查在实施阶段按仓库流程完成。

版本已推送到 `preview/lab-foundation-v1` 分支，提交 `10c4c22f875b958c7adc30cf84c7a41d56a4589c`，父提交为 `55a27be3bc717ebedda94f81a2c6d9e6d4dd7012`，其他开发者可按交接文档获取。捕获包含 38 个源码、设计输入和证据文件；哈希清单位于 `evidence/manifest.json`。捕获过程使用独立 Git index，并验证当前分支与用户 index 均保持原状。

最终独立 TypeScript 检查、Vite 构建和文档检查通过。用户已接受新增体验；v1 作为正式实现的比较基准保留。
