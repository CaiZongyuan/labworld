# Lab Word 界面约定

现有应用壳沿用[已接受的 Web 体验](web-experience.md)。Lab Viewer 的业务范围与画面接受状态见[预览记录](lab-viewer-experience.md)；v1 画面已接受，正式集成验证仍待完成。

## 应用壳与业务

壳提供导航、当前页面标题、身份、设置、通知与通用主题/语言入口。业务通过显式贡献提供页面、导航、双语文案与默认入口；壳不 import 设备或知识库专有规则。实际合同在 `packages/views/src/shell/`，路由适配在 Web。

产品名统一为 Lab Word。已接受方向是 Lab 为首要业务入口与登录后默认入口，资产库替换主导航中的知识库入口。既有知识库路由与数据保留原义，正式 Lab 集成的验收另行记录。

## 视觉与交互

共享 token 来源是 `packages/ui/src/styles.css`；文档站由此生成色板。界面使用中性工作面、紧凑标题、细分隔线与少量类别颜色，保留系统/亮色/暗色及中英文选择。

工具使用有名称的图标按钮，二值状态用开关，数值用输入或滑块。保持焦点、键盘、文本适配和窄屏可操作性。Lab 三维画布充分使用内容区，资产信息与操作不遮挡设备。

## 验收

新体验先用版本化可运行预览确认，再对正式实现比较真实布局、状态、焦点、主题与语言。已接受体验和用户明确修正沿用，不重复确认。图像是实际版本证据；本次文档首页的图片来自保留的 Lab Viewer v1，不能视作正式应用截图。
