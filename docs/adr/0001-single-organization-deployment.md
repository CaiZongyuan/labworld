# 每次部署只服务一家企业

本模板以企业知识库作为参考应用，当前目标是简单的单机部署。用户在“共享部署服务多家企业”和“每次部署只服务一家企业”之间选择后者，因此 v1 采用单租户：一次部署对应一个 Organization，企业内部可有多个 Knowledge Base，不提供跨企业切换或共享用户目录。

这一选择减少首发的成员模型、权限上下文和运维复杂度，代价是服务多家企业时需要分别部署和升级。单租户不取消企业内部的资源授权；若未来改为共享部署的多租户 SaaS，需要重新评估数据归属、账号关系和访问合同，不能把它视为单纯增加一个配置开关。

企业统一使用 Organization 这一术语；知识集合使用 Knowledge Base，不再为相同企业另加一层 Workspace。
