# 外部编写完整资产定义，发布固定版本并关联多用途表示

决定日期：2026-10-13。用户在 [Issue #85](https://github.com/CaiZongyuan/labworld/issues/85) 的资产设计访谈中确认 Q14–Q16：建模与场景编写发生在 Blender、Isaac Sim/Isaac Lab 或 Newton 程序中；型号、规格、配置字段、状态字段与单位、能力及参数说明、文档引用通过独立的资产描述文件维护。Lab World 导入、校验、登记、管理版本并提供查询。外部场景携带资产 ID、版本及各对象独立的实例 key。

Asset 是完整的可复用定义，关联查看、物理仿真和文档等用途的表示。Asset Version 发布后，定义内容及资源引用固定；修改定义或模型发布新版本，由场景显式引用并升级。相同型号的多个 Entity 复用资产，但分别保存实例配置、当前观测及记录；Asset 描述状态结构，不保存每台设备的当前状态。录制继续保留当时采用的定义和资源。

相比把全部业务信息依附于三维格式或让实例自动跟随最新版，该选择使信息合同可独立校验，版本和历史可追溯。代价是需要完整资产导入、不可变版本、多表示资源引用及场景中的精确资产关联。自定义属性在三维转换中可承载引用，但不作为完整资产定义的唯一保存位置。

能力描述与运行绑定、执行许可分别表达。当前外部来源采用 [ADR 0013](0013-source-presence-before-scene-synchronization.md) 的单向模式；引用离心机定义不能自动创建 Lab World 内置离心机程序绑定，也不能据此允许控制源设备。模拟与真实设备可复用定义并保留独立身份，沿用 [ADR 0007](0007-separate-simulated-and-physical-entity-identities.md)。

离心机作为信息合同样例，SO-101 作为当前来源同步的实测场景。完整字段、现有实现差距和消费者影响见[资产设计](../plans/asset-definition-and-external-authoring.md)。本决定记录目标合同，不表明资产导入、多表示或外部设备状态入口已经实现。
