# 后端运行设备程序，按实例独立维护状态

用户确认首轮同时实现虚拟设备的同步与控制，覆盖持续采样、即时控制、温控渐变和仪器长任务四类行为。采用内置设备程序，同类设备可共用程序，各设备实例独立维护配置、运行状态和执行进度；程序在后端运行，浏览器通过命令触发动作并从设备观测读取实际状态，三维节点负责表现和交互。

这使多个浏览器能够观察同一设备，关闭页面也不终止设备运行，代价是必须显式管理后端任务、观测持久化和生命周期。相较浏览器内模拟，状态不再随页面消失或由多个页面分别生成；每实例独立运行也不要求每台设备部署一个服务。用户上传或编辑执行代码不属于本轮范围。

后端重启后保留设备身份、参数、最后观测与记录，将原运行标为中断，由用户显式重新启动。首轮承担可辨认的中断与恢复，不自动恢复长任务；后续若增加自动恢复，需要明确检查点及重复执行语义。
