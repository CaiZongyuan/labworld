# 以可移除的真实业务交付模板教程

用户明确要求 example 像教程一样帮助使用者理解模板、覆盖大多数核心特性、仿照流程实现自己的业务，并且能容易移除。因此知识库示例采用少量业务对象和简单用户操作，真实调用 Core；运行示例、源码导读、在线教程与验收测试围绕同一份实现交付。

示例持有业务模型、Views、路由、迁移、任务处理器和对应教学资源；Core 不反向依赖示例。选择承担显式组装点、所有权清单和真实删例 CI 的维护成本，以保证替换业务后 Core 仍可运行，而非仅能隐藏示例菜单。

实现功能时同步交付在线教程，包含快速开始、跟做示例、实现自己业务、移除示例四条路径。新模板副本移除示例源码和已有生产数据的迁移分开处理，删除工具不隐式删除既有数据。
