# 模拟与真实设备共用定义，保留独立对象身份

Digital Twin Foundation V1 需要让虚拟设备验证未来实机可复用的世界模型。用户在 2026-10-02 的方案审阅中确认：模拟设备与真实设备可以引用相同的资产及能力定义、使用相同的查询和命令合同，但分别登记为独立 Entity，并可通过对象关系表达模拟对应。

这使模拟观测、真实测量、命令和任务记录各自具有明确归属，也允许并列比较模拟与真实结果。相比将同一 Entity 的 Binding 从模拟直接切为实机，该选择避免对象历史在未显式区分的情况下改变现实含义；代价是需要维护对应关系，并分别管理实例配置与记录。

Binding 的技术适配不负责合并两种对象身份。未来接入实机时复用上层语义合同，不将既有模拟 Entity 原地改成真实设备；V1 仍只实现内置虚拟设备运行。范围和审阅记录见[Foundation V1 计划](../plans/Labworld-Digital-Twin-Foundation-V1-plan.md)与[方案审阅](../reviews/2026-10-02-digital-twin-foundation-v1-plan.md)。
