# 产品范围与架构

Lab Word 的产品目标是实验室数字孪生。当前阶段聚焦设备模型的三维呈现，空间摆放与来源明确的真实状态在后续阶段建立。术语见 [CONTEXT](../../CONTEXT.md)。

## 模型与设备的关系

```text
Lab Word
  └─ Lab Viewer
       └─ Lab Layout
            └─ Equipment Instance ──使用──> Equipment Model
```

Equipment Model 是可复用三维资产；Equipment Instance 是具有独立身份和位置的一台设备。同一个模型可以表达多台设备，不能用模型文件名替代设备身份。当前单模型预览尚不建立持久布局。

## 当前呈现层边界

首版查看一份资源内嵌的 GLB，支持文件选择与拖入、自动居中与取景、旋转/缩放/平移、点击选择、回到示例和渲染指标。导入文件停留在浏览器会话，不增加服务器上传或云资产库。

保持模型原始尺度。缺失外部资源、无几何或解码失败须明确反馈，保留前一个可用模型。替换与离开页面需释放独占 GPU 资源，快速切换不能让旧结果覆盖新模型。这些是目标验收合同，生产实现仍待完成。

未来 Three.js 相关代码随 Lab 页面按需加载，正式包体预算另行实测。当前预览的构建与软件渲染指标不能证明生产性能。
