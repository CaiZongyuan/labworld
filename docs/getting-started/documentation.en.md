# Lab Word Documentation

Lab Word is a laboratory digital twin. The application stores assets, Labs, objects and layouts. Backend programs provide device observations with sources and Tasks.

## Current Capabilities And Plans

The application provides identity, membership, knowledge, files and jobs through its [platform capabilities](../guides/platform.md). Lab is the default entry after login. The accepted Viewer and Foundation previews provide the experience baseline.

Follow the paired tutorials from [persistent assets](../tutorials/persistent-assets.en.md) through identity, layouts, programs, synchronization, Tasks, history and lifecycle. The [complete journey](../tutorials/complete-foundation.en.md) uses one current checkout and one Lab throughout. It provides a separate, disposable 100 Entity, 20 device, two-browser reference load. Physical equipment integration remains future scope. [Product scope](../architecture/lab-word.en.md) defines these boundaries.

## Reading And Maintenance

Tutorials grow the same Lab business code. Independent guides provide a task, prerequisites, source locations, commands, results and failure boundaries. Existing capabilities, previews and plans carry distinct status statements.

Chinese and English pages are paired by chapter. API and configuration facts are generated from implementation. Update relevant documentation and [validation](../testing/t01-feedback-loop.md) with behavior changes; see [documentation maintenance](../guides/maintain-docs.md).
