# Triage labels

The user selected the standard vocabulary.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Incoming work needs assessment |
| needs-info | needs-info | Waiting for missing information |
| ready-for-agent | ready-for-agent | Acceptance criteria are sufficient for an implementation agent; check blockers before starting |
| ready-for-human | ready-for-human | Requires work only a human can perform |
| wontfix | wontfix | Work is intentionally not pursued |

Tickets produced by to-tickets are already specified and skip incoming-request triage. Dependency state is represented by GitHub's native blocking links, not by inventing additional triage labels.
