API 配置 ​

Node 配置直接来自运行服务的解析器。使用方法见 平台指南。生产秘密不进入文档。

当前 Lab Word Server ​

默认值由 config.ts 的实际解析器生成。Web 的 WEB_PORT 和 VITE_API_PROXY 由开发入口和 Vite 读取。

变量默认值敏感值说明
LAB_WORD_SYNTHETIC_SESSIONfalse否启用开发合成会话；需要 loopback 和配置的可选 Python 来源。
LAB_WORD_SYNTHETIC_PYTHONpython3否仅在显式 Start 开发合成会话时使用的 Python 可执行文件。
LAB_WORD_SYNTHETIC_PUBLISHER否可选 publisher.py 绝对路径；默认使用随服务提供的开发来源。
LAB_WORD_MOTION_GRACE_MS5000否Publisher 心跳和来源进度宽限毫秒数，1000–60000。
LAB_WORD_MOTION_ACK_MS3000否来源生命周期确认期限毫秒数，1000–60000。
LAB_WORD_MOTION_FIXTUREfalse否启用经过认证的合成运动测试 fixture；必须监听 loopback。
LAB_WORD_WEB_DIR否生产同源托管的 Web 构建目录；空值关闭静态托管。
LAB_WORD_HOST127.0.0.1否监听主机；兼容回退为 APP_BIND。
SERVER_PORT3000否监听端口，整数 1–65535。
APP_ORIGINhttp://127.0.0.1:5173否可信 Web origin；HTTPS 或回环 HTTP。
SESSION_ABSOLUTE_SECS604800否会话绝对有效期秒数，60–2592000。
SESSION_IDLE_SECS86400否会话空闲有效期秒数，60 至绝对有效期。
RATE_LIMIT_ENABLEDtrue否启用进程内限流，true 或 false。
RATE_LIMIT_WINDOW_SECS60否整数 1–3600；额度按 TCP peer，溢出额度不能超过主额度。
RATE_LIMIT_MAX_LOCAL_ENTRIES4096否整数 1–100000；额度按 TCP peer，溢出额度不能超过主额度。
RATE_LIMIT_REGISTRATION20否整数 1–1000000；额度按 TCP peer，溢出额度不能超过主额度。
RATE_LIMIT_REGISTRATION_FALLBACK5否整数 1–1000000；额度按 TCP peer，溢出额度不能超过主额度。
RATE_LIMIT_AUTHENTICATION60否整数 1–1000000；额度按 TCP peer，溢出额度不能超过主额度。
RATE_LIMIT_AUTHENTICATION_FALLBACK20否整数 1–1000000；额度按 TCP peer，溢出额度不能超过主额度。
RATE_LIMIT_RESOURCE600否整数 1–1000000；额度按 TCP peer，溢出额度不能超过主额度。
RATE_LIMIT_RESOURCE_FALLBACK120否整数 1–1000000；额度按 TCP peer，溢出额度不能超过主额度。
FILE_MAX_BYTES20971520否整数 1–104857600；流式字节上限。
UPLOAD_SESSION_SECS900否整数 1–3600；capability 有效期秒数。
DOWNLOAD_URL_SECS60否整数 1–300；capability 有效期秒数。
FILE_PUBLIC_ORIGINhttp://127.0.0.1:5173否字节 URL 的 origin；默认使用可信 Web origin，HTTPS 或回环 HTTP。
LAB_OBSERVATION_RETENTION_SECS86400否原始观测保留秒数（1–31536000）；保留当前属性。
LAB_RECORD_RETENTION_SECS2592000否结束记录保留秒数（1–31536000）；保留在途 Task。
LAB_WORD_DATA_DIRdata否拥有的持久数据库、字节与密钥目录；测试回退为 CONTRACT_DATA_DIRECTORY。

.env.example展示当前 Node 与 Web 配置；普通服务不读取旧数据库、Redis 或对象存储设置。服务与 Web 的启动见 TypeScript 服务基础。
