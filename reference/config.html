API 配置 ​

当前 Node 配置来自运行服务的解析器。下方另列冻结旧栈的 Settings/FIELDS 元数据，并校验旧源码哈希。使用方法见 平台指南。生产秘密不进入文档。

当前 Lab Word Server ​

默认值由 config.ts 的实际解析器生成。Web 的 WEB_PORT 和 VITE_API_PROXY 由开发入口和 Vite 读取。

变量默认值敏感值说明
LAB_WORD_HOST127.0.0.1否监听主机；兼容回退为 APP_BIND。
SERVER_PORT3000否监听端口，整数 1–65535。
APP_ORIGINhttp://127.0.0.1:5173否可信 Web origin；HTTPS 或回环 HTTP。
SESSION_ABSOLUTE_SECS604800否会话绝对有效期秒数，60–2592000。
SESSION_IDLE_SECS86400否会话空闲有效期秒数，60 至绝对有效期。
RATE_LIMIT_ENABLEDtrue否启用进程内限流，true 或 false。
RATE_LIMIT_WINDOW_SECS60否整数 1–3600；额度按 TCP peer，溢出额度不能超过主额度。
RATE_LIMIT_MAX_LOCAL_ENTRIES4096否整数 1–100000；额度按 TCP peer，溢出额度不能超过主额度。
RATE_LIMIT_REGISTRATION20否整数 1–1000000；额度按 TCP peer，溢出额度不能超过主额度。
RATE_LIMIT_REGISTRATION_FALLBACK5否整数 1–1000000；额度按 TCP peer，溢出额度不能超过主额度。
RATE_LIMIT_AUTHENTICATION60否整数 1–1000000；额度按 TCP peer，溢出额度不能超过主额度。
RATE_LIMIT_AUTHENTICATION_FALLBACK20否整数 1–1000000；额度按 TCP peer，溢出额度不能超过主额度。
RATE_LIMIT_RESOURCE600否整数 1–1000000；额度按 TCP peer，溢出额度不能超过主额度。
RATE_LIMIT_RESOURCE_FALLBACK120否整数 1–1000000；额度按 TCP peer，溢出额度不能超过主额度。
FILE_MAX_BYTES20971520否整数 1–104857600；流式字节上限。
UPLOAD_SESSION_SECS900否整数 1–3600；capability 有效期秒数。
DOWNLOAD_URL_SECS60否整数 1–300；capability 有效期秒数。
FILE_PUBLIC_ORIGINhttp://127.0.0.1:5173否字节 URL 的 origin；默认使用可信 Web origin，HTTPS 或回环 HTTP。
LAB_WORD_DATA_DIRdata否拥有的持久数据库、字节与密钥目录；测试回退为 CONTRACT_DATA_DIRECTORY。

冻结旧栈元数据 ​

变量默认值敏感值说明
DATABASE_URL必填是PostgreSQL 连接 URL。必填；绝不写入日志。
APP_BIND127.0.0.1:3000否API 监听 IP 地址和端口。
RUST_LOGinfo否结构化日志过滤器。
MIGRATION_TIMEOUT_SECS30否迁移执行时限，单位秒（1..3600）。
APP_ORIGINhttp://127.0.0.1:5173否受信任的浏览器来源。除本机回环开发外必须为 HTTPS。
SESSION_ABSOLUTE_SECS604800否会话绝对有效期，单位秒（60..2592000）。
SESSION_IDLE_SECS86400否会话空闲有效期，单位秒（60..绝对有效期）。
S3_ENDPOINT必填否内部 S3 端点（根路径）。未设置时禁用对象存储。
S3_PUBLIC_ENDPOINT必填否浏览器可访问的 S3 来源。默认取 S3_ENDPOINT；除本机回环外必须为 HTTPS。
S3_BUCKETlabos-files否应用专用的私有存储桶。
S3_REGIONus-east-1否S3 签名区域。
S3_ACCESS_KEY必填是显式 S3 访问密钥；设置 S3_ENDPOINT 时必填。
S3_SECRET_KEY必填是显式 S3 私密密钥；启用对象存储时必填，绝不写入日志。
FILE_MAX_BYTES20971520否文件字节上限，最终对象会再次校验（1..104857600）。
UPLOAD_SESSION_SECS900否上传资源/签名有效期，单位秒（1..3600）。
DOWNLOAD_URL_SECS60否下载能力有效期，单位秒（1..300）。撤销后停止新签名。
TELEMETRY_ENDPOINT必填否可选的本地 OTLP/HTTP 基础 URL（回环或 collector）；留空禁用导出。
TELEMETRY_LOG_DIRECTORY必填否可选的私有 JSON 日志目录；按小时轮转，每个服务最多保留 24 个文件。留空输出到 stdout。
TELEMETRY_QUEUE_SIZE512否有界 span 队列（64..4096）；溢出时丢弃遥测，绝不阻塞请求。
TELEMETRY_TIMEOUT_MS1000否OTLP 请求整体超时，单次尝试（50..2000 毫秒）。
TELEMETRY_METRICS_INTERVAL_MS5000否指标导出间隔（1000..60000 毫秒）。
WORKER_BIND127.0.0.1:3001否Worker 健康检查监听 IP 地址和端口。
JOB_LEASE_SECS60否任务租约有效期（5..3600 秒）。
JOB_HEARTBEAT_SECS20否租约续期间隔（1..租约秒数的一半）。
JOB_SHUTDOWN_SECS10否进程退出前完成在途工作的最长时间（1..60 秒）。
JOB_MAINTENANCE_SECS30否有界维护调度的执行间隔（1..3600 秒）。
REDIS_URL必填是可选的 redis:// 连接 URL。未设置时禁用缓存；凭据绝不写入日志。
CACHE_PREFIXlabos_threejs否部署缓存命名空间（1..100 个 ASCII 字母、数字、冒号、短横线或下划线）。
CACHE_TTL_SECS60否正文缓存 TTL，单位秒（1..3600）。PostgreSQL 始终是授权与版本的来源。
CACHE_BUDGET_MS100否每次读取的 Redis 总预算，含查找/回填（1..1000 毫秒）。
RATE_LIMIT_ENABLEDtrue否启用注册、认证和普通请求三类限流策略。
RATE_LIMIT_WINDOW_SECS60否各限流策略共享的固定窗口时长（1..3600）。
RATE_LIMIT_REGISTRATION20否启用 Redis 时每个 TCP 对等端/窗口的注册请求数（1..1000000）。
RATE_LIMIT_REGISTRATION_FALLBACK5否保守的本地注册容量（1..注册容量）。
RATE_LIMIT_AUTHENTICATION60否启用 Redis 时每个 TCP 对等端/窗口的凭据请求数（1..1000000）。
RATE_LIMIT_AUTHENTICATION_FALLBACK20否保守的本地认证容量（1..认证容量）。
RATE_LIMIT_RESOURCE600否启用 Redis 时每个 TCP 对等端/窗口的其他请求数（1..1000000）；健康探测除外。
RATE_LIMIT_RESOURCE_FALLBACK120否保守的本地资源容量（1..资源容量）。
RATE_LIMIT_MAX_LOCAL_ENTRIES4096否本地对等端/策略桶上限（1..100000）；溢出时共享保守策略窗口。
RATE_LIMIT_PREFIXlabos_threejs否Redis 限流命名空间，与正文缓存键隔离。
RATE_LIMIT_BUDGET_MS50否Redis 计数操作的绝对时限（1..1000 毫秒），超时回退本地。
MAIL_SMTP_HOST必填否SMTP 主机。未设置时停发密码重置邮件；普通注册/登录不受影响。
MAIL_SMTP_PORT1025否SMTP 端口（1..65535）；常见为 465 wrapper、587 STARTTLS、1025 本地捕获。
MAIL_SMTP_TLSlocal否wrapper、starttls 或 local（仅限回环/localhost/mailpit）。
MAIL_FROMnoreply@example.test否经过校验的发件邮箱。
MAIL_SMTP_USERNAME必填是可选 SMTP 用户名；必须同时提供密码。
MAIL_SMTP_PASSWORD必填是可选 SMTP 密码；绝不写入日志。
MAIL_TIMEOUT_SECS30否SMTP 单次尝试总时限，含 TLS/DATA/QUIT（1..300 秒）。
MAIL_ENCRYPTION_KEY必填是用于短期邮件材料的独立 32 字节十六进制密钥；API/Worker 共享，配置 SMTP 时必填。
MAIL_ENCRYPTION_KEY_VERSION1否当前正整数密钥版本；轮换前需清空或等待旧材料过期。
PASSWORD_RESET_TTL_SECS1800否重置链接有效期（60..3600 秒）；邮件材料不会超过链接有效期。
PASSWORD_RESET_COOLDOWN_SECS60否合并同一账号活跃的重置请求（1..300 秒）。
LAB_OBSERVATION_RETENTION_SECS86400否原始观测保留秒数（1..31536000）。当前逐属性观测保持不变。
LAB_RECORD_RETENTION_SECS2592000否结束命令、任务和设备事件保留秒数（1..31536000）。保留在途任务。
EXPORT_JOB_MAX_ATTEMPTS5否每个导出执行批次的有限尝试预算（1..20）。
EXPORT_MAX_ATTACHMENTS100否单次文档导出的附件数量上限（0..1000）。
EXPORT_MAX_INPUT_BYTES268435456否快照 Markdown 与附件的总字节上限（1..1073741824）。
EXPORT_MAX_OUTPUT_BYTES285212672否ZIP 总大小上限，含文件头与中央目录（1024..1107296256）。
EXPORT_RETENTION_SECS86400否导出结果与快照的保存期（60..604800 秒）。
EXPORT_TIMEOUT_SECS120否导出执行的整体预算（1..600 秒），支持协作式阻塞取消。

.env.example 仍包含冻结旧栈字段。当前 Node 服务不读取 DATABASE_URL、Redis 或 RustFS 配置。服务与 Web 的启动见 TypeScript 服务基础。
